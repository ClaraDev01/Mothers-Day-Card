# 🌸 Mothers Day Card

An interactive digital Mother's Day card with animated flowers, confetti effects and a surprise gift opening experience. Built with HTML, CSS and JavaScript.

## 🚀 Live Demo

🔗 [Access now](https://mothers-day-card-ten.vercel.app/)

## ✨ Features

- 🎁 Interactive gift opening animation
- 🌸 Floating falling flowers effect
- 💖 Confetti burst animation
- ✨ Smooth transitions and aesthetic UI
- 📱 Fully responsive — works on mobile and desktop
- 🎨 Soft greeting-card inspired design

## 🎯 How It Works

1. Open the digital card
2. Tap the gift box
3. Watch the flowers and confetti animation
4. Reveal the Mother's Day message

## 💻 How to Run Locally

```bash
git clone https://github.com/ClaraDev01/Mothers-Day-Card.git

cd Mothers-Day-Card
```

Then open:

```text
index.html
```

in your browser.
